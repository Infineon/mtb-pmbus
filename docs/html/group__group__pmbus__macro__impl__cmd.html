#define MTB_PMBUS_IMPL_CMD_PAGE_EN   (1U << 0U)

Enable the PAGE (0x00) command.

Note
This command can be disabled only if mtb_pmbus_stc_config_t::num_pages is equal to 0 or related compile-time option is disabled.
