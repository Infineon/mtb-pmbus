◆ mtb_pmbus_handle_cmd_page_events_t

typedef uint8_t(* mtb_pmbus_handle_cmd_page_events_t) (mtb_pmbus_cmd_events_t event, bool is_write, int32_t page)

Provides the typedef for the callback function called in ISR to notify the user about occurrences of mtb_pmbus_cmd_events_t related to PAGE commands.

The requested active page can be accepted or rejected by setting the return value for callback: 0U - NACK is sent after receiving the requested value, 1U - ACK is sent after receiving the requested value.
